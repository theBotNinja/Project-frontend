# HerShield Frontend

Frontend for **HerShield – AI-Powered Women Safety System**.

Built with React.js, this application provides an intuitive interface for users to report incidents, trigger emergency alerts, view safety heatmaps, and interact with an AI-powered safety chatbot.

## Features

- User Authentication
- Emergency Panic Button
- Incident Reporting
- Live Safety Heatmap
- AI Safety Chatbot
- Admin Dashboard
- Responsive UI

## Tech Stack

- React.js
- React Router
- Axios
- Leaflet & React-Leaflet
- Recharts
- React Hot Toast

## Installation

```bash
git clone <repo-url>
npm install
npm start
```

## Environment Variables

Create a `.env` file:

```env
REACT_APP_API_URL=http://localhost:5000
```
